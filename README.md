# TerraWeek2
!!!! MULTI-WEEK PROJECT
-----------
The Basics
-----------

This is my submission for Terra Week 2
It is a top-down 2d Game
This is just a basic fishing game in which the player must cast their rod and complete the skill checks to catch fish
You can then use the coins, which for now are automatically converted from the fish's sell value, to buy bait.

-----------
The Why
-----------
I made this game because I've always loved fishing, especially in games. For as long as I can remember, I've been fishing in games,
whether it was back in, like, 2020 fishing in Hypixel Skyblock or even now playing the latest fishing games. 
Because of that, I thought to myself, "Why not make your own fishing game? It'll make the experience 10x more fun and rewarding".
So while I am sharing this game with others, it was mainly for my own satisfaction.

-----------
The Objective
-----------
Catch fish
Buy bait
Catch more fish
Upgrade your rod
More will be added later
Enjoy the Game!
----------------------
Inputs and controls
----------------------
W - moves the player up
A - moves the player left
S - moves the player down
D - moves the player right
M1(Character-Select) allows you to select the character
M1(Near Water) allows the player to fish, make sure to hold the mouse button and try to get that white pin on the green zone
M1(In shop) Click on the prices to buy and item and the close button to return
Tab - Tab to Open inventory
F - Interact with the shopkeep
Q - Input for the Quick Time Event Mini-Game
E - Input for the Quick Time Event Mini-Game

-----------
Hints
-----------
You MUST be near water to fish.
The Sell Value is determined by base value * weight * score on the casting skill check
Score on the Casting Skill Check - Perfect(2x), Good(1.5x) Meh(1x) Bad(0.5x)
Base Value - Clownfish(25), Cod(25), Goldfish(15)
Weight Values Clownfish(0.1 - 2.5), Cod(0.1-5), Goldfish(0.1-3)
Bait descriptions are in the shop 
On the QuickTime event, you must get 10 in a row to catch a fish
Left-click on baits bought in the inventory to use them
